# E-commerce Customer Purchase Intention Analysis

## Project Overview
This project analyses e-commerce website session data using Microsoft Power BI. The dashboard helps understand visitor behaviour, purchase patterns, and factors related to purchase conversion.

## Dataset Information
- **Dataset:** Online Shoppers Purchasing Intention Dataset
- **Source:** UCI Machine Learning Repository
- **Total Records:** 12,330
- **Total Columns:** 18

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Features
- Interactive slicers for Month, Region, Weekend, Special Day, and Visitor Type.
- KPI cards showing total sessions, purchase sessions, non-purchase sessions, conversion rate, average product duration, and average bounce rate.
- Monthly session analysis.
- Purchase sessions by region.
- Purchase behaviour by month and visitor type.
- Purchase versus non-purchase session analysis.

## Key Measures
- Total Sessions
- Purchase Sessions
- Non-Purchase Sessions
- Conversion Rate %
- Average Product Duration
- Average Bounce Rate

## Key Insights
- The dataset contains 12,330 website sessions.
- 2,000+ sessions resulted in purchases.
- Approximately 15.47% of sessions resulted in purchases.
- Most website sessions did not result in a purchase.
- Visitor types show different purchase patterns across months.

## Project Objective
The objective is to explore website visitor behaviour and understand purchasing patterns through interactive data visualisation.
